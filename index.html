Research

Hybrid program analysis for AI native infrastructure

My research builds on the Android lineage: Jitana's on-demand virtual graph loader and ReHAna's recovery of code hidden by Java reflection and dynamic code loading. I apply these principles across the AI stack, combining static and dynamic analysis, compiler infrastructure, and runtime evidence to make software changes easier to inspect, test, explain, and review.

VerifyD brings interpretability and verification into AI-assisted software engineering through static and dynamic checks, compiler-aware evidence, provenance, and human review. Its Rust and Mojo tooling builds on the virtual graph loader.
